# 검증 기록 · v0.2.0

## 로컬 자동 검사
- Node 단위/회귀/레벨/빌드 검사: 55개 통과 (현재 기록).
- 12개 모든 해답을 풀이기로 다시 확인. 최소 걸음 2, 3, 6, 6, 8, 8, 10, 12, 12, 9, 14, 16.
- 11개 스테이지에서 실제 합법 이동만으로 도달하는 양쪽 막힘 경로 확인. 2번은 의도적으로 선택이 없는 학습용.
- Chromium 실제 화면에서 12개를 키보드 입력으로 해결하고 성공 후 되돌리기 확인.
- 긴 마우스 드래그/긴 터치 스와이프 한 번에 한 칸, 인접 칸 탭, 제스처 취소 확인.
- 힌트 시범을 끝까지 본 뒤 원래 배치/완료 여부가 유지됨을 확인.
- 320, 360, 390, 768, 844px 폭에서 가로 넘침 없음.
- 저장 손상·저장 금지 시 게임 진행 유지. 저장 재실행 및 되돌리기 세션 검사.

## 실행 환경의 한계
샌드박스 Chromium은 외부·로컬 HTTP 탐색이 관리자 정책으로 막혀 있다. 정책을 수정하지 않고 로컬 파일 내용을 set_content로 렌더링했다.
샌드박스 UI 검사의 저장/재접속에는 메모리 저장 어댑터를 사용했다. 실제 localStorage 구현/HTTP 제공은 GitHub Actions의 기본 브라우저 검사로 별도 확인하도록 구성했다.
실제 Android/iPhone 기기로 테스트했다고 주장하지 않는다. 화면 녹화/유저 테스트로 체감 난이도를 검증하지 않았다.

## PC에서 우선 볼 것
1. 1~3번: 규칙 시연 뒤 어느 꼬리가 없어지는지 예측 가능한가.
2. 4~9번: 무작정 가능한 칸만 누르지 않고 이동 순서를 생각하는가.
3. 10~12번: 집에서 나오기/우회 발상이 납득되는가.
4. 막힘 후 Z로 즉시 복구되는가. 무효 입력은 걸음에 포함되지 않는가.
5. 새로고침 후 진행·캐릭터 선택이 복구되고 되돌리기도 가능한가.
6. 시범이 실제 진행을 덮어쓰지 않는가. PC 모바일 폭 보기와 실제 휴대전화 화면을 모두 확인했는가.

## 리뷰
규칙은 v0.1과 동일. 성공→막힘 순서, 저장 리플레이 검증, 시범 격리, 단축키 입력창/대화상자 격리, 생성 사이트의 상대 경로를 점검했다.
독립 리뷰 에이전트 검토는 수행하지 않았다. 공개 배포는 CI 결과와 Pages Deploy 단계를 따로 확인해야 한다.
