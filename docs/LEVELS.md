# 스테이지 제작표 · v0.2.0

좌표는 좌상단 (0,0), 몸 배열은 머리→꼬리. 난이도는 실제 플레이 테스트 전 임시 분류입니다. 최소 걸음은 난이도 점수가 아닙니다.

|번호|이름|분류|최소 걸음|기준 경로 선택 지점|막힘 예시 길이|
|---|---|---|---:|---:|---:|
|1|한 조각씩|입문|2|2|5|
|2|네가 열어주는 길|입문|3|0|없음|
|3|머리만 남았네|입문|6|6|5|
|4|어느 쪽부터?|기초|6|6|5|
|5|한 조각 더 기다려|기초|8|8|5|
|6|작은 막다른 길|기초|8|8|6|
|7|네가 움직일 자리|응용|10|10|7|
|8|빌렸다가 돌려주기|응용|12|11|7|
|9|먼저 멀어지기|응용|12|12|5|
|10|집에서도 한 걸음|도전|9|9|3|
|11|들어갈 순서|도전|14|14|7|
|12|꼬리를 기다려|도전|16|16|8|

2번의 선택지가 없는 구성은 규칙 학습용입니다. 4번 이후는 두 개 이상의 선택 지점이 있습니다. 탐색량 상한에 닿으면 해답 없음이 아니라 검증 미완료입니다.

## 01. 한 조각씩

**발견:** 교환

```text
#######
#.....#
#.....#
#.....#
#######
```
빨강 머리→꼬리: `[[2, 1], [1, 1], [1, 2]]`  
파랑 머리→꼬리: `[[4, 3], [5, 3], [5, 2]]`  
집(빨강, 파랑): `[[3, 1], [3, 3]]`

힌트 1: 빨강을 움직일 때, 파랑 꼬리를 보세요.

힌트 2: 빨강은 오른쪽, 파랑은 왼쪽으로 한 칸씩 가면 돼요.

<details><summary>해답과 막힘 예시 (0=빨강, 1=파랑, U/R/D/L=위/오른쪽/아래/왼쪽)</summary>

해답: `0R 1L`

막힘: `0R 0R 1U 1R 1U`

</details>
