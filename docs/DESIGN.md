# 몸 나눠쓰기 v0.2 설계

## 확정 범위
모바일 세로형 우선. PC에서 마우스·키보드로 동일한 규칙을 테스트한다.
추가 장치/목숨/시간 제한/상업 시스템/서버는 없다. 입문·기초·응용·도전 각 3개, 총 12개를 검증한다.

## 규칙
몸 배열은 머리부터 꼬리 순서. 이동 전 빈칸을 확인한 다음 내 머리 +1, 상대 꼬리 -1을 원자적으로 적용한다.
상대가 머리만 남으면 빌릴 수 없다. 이번에 없어질 꼬리도 아직 점유한 칸이다. 집 위에서도 이동 가능하다.
성공을 먼저 판정하고, 실패는 미해결 상태에서 양쪽의 합법 이동이 모두 없을 때만 안내한다.
합법 이동이 남은 막힘은 자동 판정하지 않는다. 무효 입력은 턴/실패/걸음에 포함하지 않는다.

## 세션
무제한 되돌리기. 현재 걸음은 최종 경로 길이. 단계별 배치/선택/힌트/완료/최고 기록/로컬 테스트 통계를 저장한다.
저장은 서버가 아닌 해당 브라우저 localStorage. 브라우저·주소가 다르면 공유하지 않는다.
재접속 시 행동 목록을 규칙 엔진으로 다시 실행하여 검증한다. 레벨 지문이 바뀌면 해당 레벨의 옛 진행만 폐기한다.
잘못된 저장/저장 차단은 게임 진행을 막지 않으며 알린다. 활성 탭 복귀 시 입력을 초기화한다.

## 입력과 화면
모바일: 얼굴 스와이프 한 번에 한 칸. 캐릭터 선택+인접 칸 탭/방향 버튼 제공. 드래그 취소·다중 터치를 무효 처리.
PC: 1/2 선택, 방향키/WASD 이동, Z 초기화가 아닌 되돌리기, R 초기화 확인, H 힌트. 반복 키 입력으로 자동 전진하지 않는다.
대화상자 열림/입력창 포커스/브라우저 단축키에는 게임 키를 적용하지 않는다.
선택 및 다음에 없어질 상대 꼬리를 시각화. 색 이외에 원/마름모로 구분한다. reduce-motion 존중.
PC 모바일 폭 미리보기는 레이아웃 검사 보조일 뿐 실기기 검증 대체가 아니다.

## 힌트와 진행
모든 스테이지를 테스트용으로 선택 가능. 1 관찰, 2 발상, 3 원본 배치의 단계별 시범.
시범은 별도 세션으로 재생하고 종료 시 원래 배치·기록 복귀. 자동 해결이나 현재 진행 덮어쓰기 금지.
난이도는 기획 분류이며 실제 사용자 난이도 검증 전이다. 스테이지마다 해답·대표 오답/막힘 경로를 검증한다.

## 배포
HTML/CSS/JavaScript 정적 파일, 실행 의존성 없음. Node 22+로 개발 서버/단위 검사/빌드.
GitHub Pages를 우선 사용. 상대 경로로 /project-d/ 및 로컬 실행 모두 지원.
Pages 초기 활성화는 저장소 관리자 설정이 필요할 수 있다. 실제 배포 URL 응답 확인 전 완료라고 하지 않는다.
서비스 워커와 계정/온라인 동기화는 이번 범위에서 제외한다.
